# 💡 Solución

---
Se ejecuta este insert into 
```sql
insert Es_estProVer_Asignacion_Usuarios
select 
	Cod_EstPro, Cod_Version, Cod_Caracteristica_Operario, Secuencia + 1, GETDATE(),'ATALLAS'
from Es_estProVer_Asignacion_Usuarios where Cod_Usuario = 'JMOLINA' and Cod_EstPro = '07850'
```
